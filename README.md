# Mobile-Sales-Dashboard

A data-driven dashboard built using Power BI, designed to visualize mobile sales data and provide insights into sales performance.

## 📊 Overview & Purpose

Mobile-Sales-Dashboard helps you visualize and analyse mobile-sales related metrics — including total sales, sales by model/brand/region, trends over time, and other KPIs — in a clean interactive dashboard.  
It’s useful for sales teams, analysts, small businesses or anyone looking to get quick visual insights from raw sales data.

## 🧰 Built With / Tech Stack

- Power BI — for data modelling, visualization and dashboard generation  
- (.pbix file) — dashboard file included in this repo
